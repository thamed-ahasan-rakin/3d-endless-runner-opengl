# Game Features

## Feature description provided with the project

Players can enjoy endless running gameplay with swiping controls (left, right, up, down), use power-ups like jetpacks, hoverboards, magnets, and shields. Cheat modes let players collect unlimited coins, become invincible with no crashes, and toggle speed boosts. The weather can be changed between day, night, and rain. The player has three lives and can destroy obstacles three times with a special power.
